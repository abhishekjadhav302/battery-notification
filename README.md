# 🔋 Battery Notification

A lightweight desktop application that displays custom notifications based on your laptop's battery percentage.

## 💡 Why I Created This Application

I was frustrated with having to replace my laptop battery multiple times. When I replaced my battery recently, the technician suggested keeping the battery level between **20% and 80%** to help maintain battery health.

However, I couldn't find a convenient built-in setting on my laptop to notify me when the battery reached these levels.

So, I decided to build my own desktop application to solve this problem.

## ⚙️ How It Works

The application runs in the background and checks the laptop's battery percentage every **30 seconds**.

It displays a custom notification when:

* 🔋 Battery reaches **20%** → Connect the charger.
* ⚡ Battery reaches **80%** → Consider disconnecting the charger.

The goal is to make it easier to monitor the battery without constantly checking the battery percentage manually.

## 🎯 Project Goal

This project was created as a practical solution to a real-world problem I personally experienced, while also giving me an opportunity to practice Java desktop application development.

## 🚀 Features

* Runs in the background
* Checks battery percentage every 30 seconds
* Custom battery notifications
* Low-battery notification at 20%
* High-battery notification at 80%
* Lightweight and simple to use
